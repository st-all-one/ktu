# O repositório knudge explicado a uma criança de 5 anos 🐻

Imagina que tens um **bloco de notas mágico** para o teu brinquedo preferido — um robô que faz programas de computador (chama-se *agente de IA*).

O problema é que esse robô **esquece-se de tudo** quando vai dormir (quando acaba o trabalho dele). É como se lhe apagássemos a memória.

O **knudge** é um **caderninho de memória** para esse robô:

- 📝 O robô escreve coisas que aprendeu em **papeizinhos** (ficheiros com notas).
- 🔍 Depois, antes de fazer qualquer coisa, ele **procura** no caderninho para se lembrar do que já sabe.
- 🗂️ O caderninho tem um **índice** (como os desenhos no fim dos livros) que ajuda a encontrar as coisas depressa.
- 🗑️ Se o Índice se estraga, não faz mal — ele **constrói outro** a partir dos papeizinhos. Os papeizinhos é que são importantes.
- 🤖 Especialmente esperto: se o robô tentar escrever uma coisa **igualzinha** a uma que já está no caderno, o caderninho diz "ops, já sabemos isso!" e junta tudo, em vez de repetir.

Também tem um **sinal luminoso** que avisa: "Ei! Já não te lembravas desta coisa que aprendeste ontem?"

Resumindo: é um **caderno de memória com mágica** para robôs de computador, feito com uma linguagem chamada Rust, e o seu lema é: **"escreve o que aprendes, e lembra-te de procurar antes de decidir."**
